## Remaining gaps (v7)

1. **Convergence standoffs (stop cause of HEAD on H7-CORE and the spread NET-CORE).** H7 m3: /SPI_SCK vs VDD_3V3 near
   U5 (pad 129.95, 164.25) from iteration 31; NET-CORE spread: /ETH_TXD0 in the RMII field. The strict end step and the
   new rip-up cascade did not open them. Results depend on the build (e1 and f converged / passed). Same failure class
   as M2 gap 2.
2. **DRU length limit not routed.** `Net.max_len` is read but not used: m3 has /ETH_* RMII 52.6 mm > 50 mm (KiCad
   length_out_of_range). It passed before by chance.
3. **Priced web is slow:** about 2 x per iteration on H7-CORE (spatial query per via expansion); run m1 was stopped at
   iteration 13 (timebox).
4. GND via count did not drop on NET-CORE (125 vs 123): most are plane fan-outs (one via per GND SMD pad, DESIGN 5a).
   On H7-CORE the v6 total (563) is still above the existing route (526), with no RP-001 exemptions (existing: 19).
5. Convergence standoffs at the 1.0 mm return radius (M2 note): e1 converged with none; m3 shows one at U5.
